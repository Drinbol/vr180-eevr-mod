# vr180-eevr-mod

Blender Eevee VR180 视频渲染工具（CUBE→EQUI 转换版）。

> **出处**：基于 [EternalTrail/eeVR](https://github.com/EternalTrail/eeVR) 改造
> （readme.txt 中为"おいも版カスタムeeVR with CUBE to EQUI ver0.5"），
> 遵循上游 eeVR 的原始许可证，本仓库仅作个人存档。

## 内容

| 文件 | 说明 |
|---|---|
| `VRRenderer_CUBE_TO_EQU_ver_05.py` | 主渲染脚本（Blender 内运行） |
| `_EEVR_Render_For_separate_2.bat` | 分批渲染自动化 |
| `_EEVR_Render_For_separate_2並列 copy.bat` | 并行渲染版 |
| `readme.txt` | 原版说明（日文） |

blend 工程、参考图、遮罩图等素材不入库。
